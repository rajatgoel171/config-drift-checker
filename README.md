# Config Drift Checker

A dependency-free tool for comparing expected deployment configuration against actual environment configuration. It helps catch missing keys, changed values, and unexpected settings before they become production issues.

## What This Demonstrates

- Deployment and operations awareness
- Configuration validation
- Structured diff reporting
- Practical CLI design for backend teams

## Features

- Missing key detection
- Unexpected key detection
- Value mismatch reporting
- JSON input and JSON output
- Unit-tested diff engine

## Run

```bash
npm test
npm run demo
```
